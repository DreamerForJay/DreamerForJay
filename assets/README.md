# Profile visuals

These SVG files are checked in so the profile does not require a live third-party image generator on each visit. They contain no JavaScript and need no GitHub Actions or credentials. The key profile information remains readable as text in README.md.

- `header.svg`: generated with [Capsule Render](https://github.com/kyechan99/capsule-render) (MIT). Deep navy/teal gradient, waving shape, one-time text fade.
- `focus.svg`: generated with [Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg) (MIT). Two short, looping research/engineering taglines. Its embedded Fira Code font is covered by `FiraCode-OFL.txt`.

Upstream licenses are included alongside these assets. Generated on 2026-10-03.
